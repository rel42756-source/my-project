مشروع EVENTIA — تنظيم المناسبات

التشغيل في Visual Studio Code:
1) فكّي ضغط EVENTIA.zip في مجلد واضح.
2) افتحي Visual Studio Code ثم File > Open Folder واختاري مجلد EVENTIA.
3) ثبّتي إضافة Live Server من Extensions (إذا لم تكن موجودة).
4) اضغطي بزر الفأرة الأيمن على index.html ثم Open with Live Server.

صفحات المشروع:
- index.html: الصفحة الرئيسية.
- about.html: من نحن وفكرة المشروع.
- events.html: المناسبات والباقات والأسعار التوضيحية.
- booking.html: نموذج طلب الحجز.
- style.css: التصميم والألوان والتجاوب مع الهاتف.
- script.js: تحديث الباقات والسعر والتحقق التجريبي من نموذج الحجز.

ملاحظات:
- الموقع مبني باستخدام HTML وCSS وJavaScript فقط، دون أطر عمل.
- الصور والخطوط في النسخة الحالية تُحمّل من الإنترنت، لذلك يلزم الاتصال بالإنترنت لعرضها.
- الأسعار أمثلة توضيحية لمشروع دراسي وليست عروضاً فعلية.
- نموذج الحجز تجريبي ولا يخزن البيانات أو يرسلها لخادم.
